# MLDM: Multiple-Location Disease Mapping

This package implements a hierarchical Bayesian disease mapping analysis for settings where individuals are observed at multiple locations. The method jointly models each individual's complete set of observed locations using a multinomial likelihood, separating spatially structured, disease group-specific risk from individual-level covariate effects and random effects that account for within-individual correlation across repeated locations. The model is fit using Markov chain Monte Carlo sampling techniques. Please see the "MLDM\_Model\_Details" and "MLDM\_Example" folders for more specific information regarding the statistical model and package use details, respectively.
